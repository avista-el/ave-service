# Alphavista API — Deployment Guide

## Render (production)

### Prerequisites
- Render account at https://render.com
- MongoDB Atlas cluster (free tier works)
- Upstash Redis **or** Render Redis add-on
- Cloudinary account (free tier works)
- Paystack / Flutterwave accounts with webhook secrets
- Resend account for transactional email
- (Optional) Meilisearch Cloud or a separate Render service

---

### Step 1 — Connect the repo

1. Push this repo to GitHub / GitLab.
2. In Render dashboard → **New → Blueprint**.
3. Select your repo, point to `backend/render.yaml`.
4. Render will create a **Web Service** called `alphavista-api`.

---

### Step 2 — Set secret environment variables

In the Render dashboard for the `alphavista-api` service → **Environment**, add:

| Key | Where to find it |
|---|---|
| `MONGODB_URI` | Atlas → Connect → Drivers. URL-encode special chars in password (`#` → `%23`) |
| `REDIS_URL` | Render Redis add-on → Connect → External URL, or Upstash console |
| `CLOUDINARY_CLOUD_NAME` | Cloudinary console → Settings |
| `CLOUDINARY_API_KEY` | Cloudinary console → Settings |
| `CLOUDINARY_API_SECRET` | Cloudinary console → Settings |
| `PAYSTACK_SECRET_KEY` | Paystack dashboard → Settings → API Keys |
| `PAYSTACK_WEBHOOK_SECRET` | Paystack dashboard → Settings → Webhooks |
| `FLUTTERWAVE_SECRET_KEY` | Flutterwave dashboard → Settings → API Keys |
| `RESEND_API_KEY` | Resend dashboard → API Keys |
| `CLIENT_ORIGIN` | Your frontend URL, e.g. `https://alphavista.ng` |
| `STOREFRONT_URL` | Same as above |
| `MEILISEARCH_HOST` | Meilisearch Cloud URL or self-hosted service URL |
| `MEILISEARCH_API_KEY` | Meilisearch master key |

`JWT_SECRET` and `JWT_REFRESH_SECRET` are auto-generated by Render (see `render.yaml`).

---

### Step 3 — Register webhooks with payment providers

After the service is deployed and you have a stable URL (e.g. `https://alphavista-api.onrender.com`):

**Paystack:**
- Dashboard → Settings → Webhooks → Add URL:
  `https://alphavista-api.onrender.com/v1/payments/webhooks/paystack`
- Copy the webhook secret into `PAYSTACK_WEBHOOK_SECRET`.

**Flutterwave:**
- Dashboard → Settings → Webhooks:
  `https://alphavista-api.onrender.com/v1/payments/webhooks/flutterwave`
- Set the hash secret and copy it to `FLUTTERWAVE_SECRET_KEY` (Flutterwave uses the same secret key for both webhook verification and API calls).

---

### Step 4 — Seed Meilisearch index

After first deploy, call the reindex endpoint to populate the search index:

```bash
curl -X POST https://alphavista-api.onrender.com/v1/admin/search/reindex \
  -H "Authorization: Bearer <admin_access_token>"
```

---

### Step 5 — Verify

```bash
# Health check
curl https://alphavista-api.onrender.com/health

# Swagger docs (if SWAGGER_ENABLED=true)
open https://alphavista-api.onrender.com/docs
```

## Local development

```bash
# 1. Copy env file and fill in your values
cp .env.example .env

# 2. Start infrastructure (MongoDB replica set + Redis + Meilisearch)
docker compose up -d mongo redis meilisearch

# 3. Wait ~15 s for MongoDB replica set to initialise, then:
npm run start:dev
```

API runs at http://localhost:4000  
Swagger docs at http://localhost:4000/docs

---

## Docker (standalone)

```bash
docker build -t alphavista-api .
docker run -p 3001:3001 --env-file .env alphavista-api
```

---

## MongoDB replica set note

Multi-document transactions (used for order creation + stock reservation) require a MongoDB replica set. MongoDB Atlas provides this by default. For local development the `docker-compose.yml` initialises a single-node replica set automatically via `scripts/mongo-init.js`.
